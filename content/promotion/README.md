# Caption templates

Each locale has one reviewed template per tone. Placeholders are limited to `{hook}`, `{verdict}`, and `{url}`. The engine supplies a verdict already calculated from the cached analysis and a tracked link. Keep X captions under 280 characters with long valid Riot IDs, and keep the heuristic and unofficial disclosure in each YouTube description. Do not claim that Riot forced a loss or insult teammates. Add translations with tests in `tests/promotion.test.mjs`.
